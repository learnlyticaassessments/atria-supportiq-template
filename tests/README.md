# tests/

Put any **learner-visible smoke tests** here (named `test_*.py`) if a lab ships them — the
GitHub Actions `grade` workflow runs them on every push for fast feedback.

The **official hidden tests are not stored here.** When you click **Run Test** in the platform,
the grader injects the real tests for that day, runs them against your committed code, and records
your result. Keeping hidden tests out of this public repo preserves assessment integrity.
